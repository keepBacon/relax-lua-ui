# Relax UI — P0 稳定性审计（2026-11-22）

## 来源与范围

依据仓库 `lib/Loader.luau`、`public/Loader.luau`、`scripts/bundle.mjs`、`ControlStates`、`OverlayStack`、`ModuleCards` 和原路线图 `RUI-P0-01 / 02` 审计。此文档只记录**源码与 CI 可证明的内容**，Android 真机验收单独记录。

## 第一轮（P0-01 / P0-02）

### P0-01 发布入口

- [x] `lib/Loader.luau` 和 `public/Loader.luau` 统一指向 `keepBacon/relax-lua-ui`。
- [x] `relaxcommit` 支持 7～40 位十六进制 SHA，保留旧 `riftcommit` 别名；冲突配置在下载前报错。
- [x] 网络错误、空响应、编译错误、初始化错误和无效 API 均显式失败；**绝不回退到上游或者另一修订**。
- [x] README 和 `examples/hub.luau` 统一仓库；短入口 `p` 下载失败显示具体 URL。
- [x] `public/Loader.luau` 与 `lib/Loader.luau` 构建产物一致性、README 演示入口的 `DEMO` 密钥、核心运行库的组件源码加入回归检查。
- [ ] **真机网络验证**：不同 Roblox Android 执行环境、代理/境内网络和固定提交的实际下载（需用户设备）。

### P0-02 锁定状态与弹层

- [x] 快速重复打开同一锁定控件复用已有弹窗；不同控件先关闭旧弹窗并清理旧遮罩。
- [x] 锁原因更新时打开中的说明可以刷新，解除锁定立即注销弹层，不改变控件值。
- [x] 每次锁图标振动取消前一轮动画；解锁或控件销毁后不遗留左右偏移。
- [x] 锁遮罩的点击信号纳入 Hub 的清理范围，弹窗关闭/销毁仍遵循 OverlayStack。
- [x] 对短视口限制弹窗正文尺寸，长文支持滚动；视口变化后重新测量。
- [x] Lune 增加 100 次锁定/打开/关闭/解锁的堆叠检查，API 与视觉状态均需保持一致。
- [ ] **真机视觉与输入验收**：短屏、中文长文本、输入法、全屏/多指手势的实际渲染和触摸（需截图/录像）。

## 第二轮验收清单（P0-03 / P0-04）

1. Android 横屏的 70%/100%/140% UI Scale；4:3、16:9、20:9 及狭窄窗口。
2. Dropdown、ColorPicker、PlayerPicker、Keybind、二级分页及 Modal 的边界避让。
3. 悬浮球长按一秒、多指冲突和手势取消；输入法启闭后焦点恢复。
4. 图标资源缺失的回退显示（不出现方框或空白）。
5. 预览固定场景与状态矩阵：ModuleCard、二级分页、数据组件、锁定弹窗、设置、主题；建立可复测的截图清单。

## 不变约束

- ModuleCard 使用用户指定图标/文字/展开收藏/开关结构，不显示 Ready 状态胶囊。
- Locked 与 Available 保持两态；原版 RiftUI 细条计时通知不改样式；DEMO 演示密钥不移除。
- 主面板文字不使用 CanvasGroup 整组透明或缩放；每个分页独立尺寸储存。
- CI 通过不能等同于 Android 真机、真实 GPU 帧时间或触屏手感通过。
