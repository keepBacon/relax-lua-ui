# Relax UI — 面板尺寸与右下角拖拽缩放

从 2026-11-22 起，主面板改用更宽的默认布局：普通页面目标宽度 620，设置页 680 逻辑像素；初始面板高 380 逻辑像素，短页面不再强制收缩到内容恰好高度。实际大小仍由屏幕边界约束。

## 操作

主面板右下角保留不可见的 34×34px 拖动触控区；**不显示三条斜线或其他提示图案**。拖动这个角落仍能改变窗口宽高。

- 支持 Roblox Touch 与鼠标，继承已有 `bindPointerDrag` 的指针身份捕获、冲突规避和生命周期清理。
- 缩放时直接改变 Frame 的尺寸和双列响应布局，不使用 `UIScale` 放大字体或整页位图。
- 可拖动到一列布局；宽度小于 550 逻辑像素时，左右两列内容会合并为单列。
- 限制最大宽高，防止把窗口拖到屏幕边缘或覆盖底部 Dock。每个一级分页和二级分页独立保存尺寸到 `setup.json.PanelSizes`（按分组/主页/子页区分），加载时恢复；旧全局 `PanelSize` 不再共享到所有页。
- 视口变化（横竖屏等）会重新按安全边界裁剪旧尺寸；当屏幕重新变宽时不会丢失最后一次用户选择。
- 通过 `CreateHub({ Resizable = false })` 可关闭底部把手。
- `Hub:GetPanelSize()` 返回当前尺寸 `Vector2`。
- `Hub:SetPanelSize(width, height, save?)` 以逻辑像素设置尺寸，`save=false` 可跳过即时写入。
- `Hub:ResetPanelSize()` 只重置当前分页的手动尺寸，其它分页不受影响。

```luau
local Hub = Rift:CreateHub({ Name = "Example", Resizable = true })
Hub:SetPanelSize(680, 440)
local size = Hub:GetPanelSize()
print(size.X, size.Y)
Hub:ResetPanelSize()
```

设计约束：主界面保持屏幕居中并从中心扩展；拖动位移采用两倍逻辑像素变换，以便被拖动的右下角跟随手指。右下角留出约 34×34 的拖动触控目标，并避免添加额外全局循环。保留原版 RiftUI 通知、密钥认证、导航及背景样式。

## 验收

1. 面板较窄时所有模块文本、标题和按钮均可见，双列切换单列无需重启。
2. 拖动与滚动不会共享触点；快速多次拖拽、切换页面、关闭与重开后没有残留捕获。
3. 手动尺寸重新打开 Hub 后恢复；点击「重置面板尺寸」后恢复自动尺寸。
4. 自动化测试包括发布包同步、模块标记、Luau 运行时回归。Android 真机触控响应和不同 DPI 的视觉结果需单独复测。

## 分页独立尺寸

首页、模块、设置和任意二级分页分别记录宽度与高度；切换分页时立即恢复对应尺寸，没保存的分页使用自动布局，不继承上一页窗口高度。一次拖拽严格绑定起始分页；过程中切页不会把已拖尺寸保存到其他分页。窗口保持居中，不创建全局输入循环。
